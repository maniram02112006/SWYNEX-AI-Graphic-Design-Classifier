# SWYNEX Task 1: AI Problem Design

## Project Title
AI-Based Graphic Design Style Classifier

## Problem Statement
Graphic designers often work with large collections of posters and visual designs. Manually organizing these designs by style can take time. This project proposes an AI model that classifies design images into categories such as cinematic, minimalist, typography, sports, and vintage.

## Target Users
Graphic designers, design students, creative agencies, and digital content creators.

## AI Use Case
Image classification.

## Input
A graphic design image or poster.

## Output
A predicted design-style category.

## Data Source
A small collection of labelled design images that are appropriately licensed or created for this project.

## Constraints
- Limited number of labelled images.
- Different styles may share similar visual features.
- Image quality, lighting, color, and typography may affect predictions.
- The model may misclassify designs that combine multiple styles.

## Evaluation Approach
Divide the labelled images into training and test sets. Evaluate predictions using accuracy, precision, recall, and a confusion matrix. Document the model's limitations and actual test results.

## Success Criteria
Define a target accuracy before testing and report the actual result. Do not claim a target has been achieved without supporting test results.

## Expected Outcome
A prototype that automatically suggests a graphic design style category for an image.

## Future Improvements
- Build a simple image-upload interface.
- Use a pretrained image classification model.
- Suggest color palettes and complementary fonts.
- Add recommendations for poster layouts.

## Conclusion
This project explores how AI can help organize graphic design assets and support creative workflows.
